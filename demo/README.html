The demos actually require MulleUICore to run. It's too tedious to set everything up again for linking with glfw and basically that's what MulleUICore is there for anyway.

Build and Run

This is a mulle-sde project.

It comes with its own virtual environment and list of dependencies. To fetch and build everything say:

mulle-sde craft

Then run the executables found in kitchen/Debug.
